# デモ用プロンプト

研修で使用する3つのデモ用プロンプトだけを、このディレクトリに実演順で配置しています。
デモ中に結果を読みやすくするため、各プロンプトは出力件数と項目数を絞っています。

| デモ | ファイル | 内容 |
|---|---|---|
| 1 | `01-code-review.md` | アプリケーションコード中心のセキュリティレビュー |
| 2 | `02-infrastructure-review.md` | Terraformとシステム前提を使ったインフラレビュー |
| 3 | `03-cross-layer-review.md` | コードとインフラを横断したAttack Pathのレビュー |

実演ではこの3ファイルを上から順に使用します。
